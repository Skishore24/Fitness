# FITTRACK — Mobile Android App (React Native & Health Connect)

Please refer to the root [README.md](../README.md) for complete end-to-end instructions.

### Quick Commands

#### Start Metro
```powershell
npx react-native start
```

#### Run on Connected Android Device
```powershell
npx react-native run-android
```

#### Run Unit Tests
```powershell
npm test -- fitnessCalculations
```

#### Build Local Release APK
```powershell
cd android
.\gradlew.bat assembleRelease
```

Generated APK location:
`android/app/build/outputs/apk/release/app-release.apk`
